# Plano de Estudos: Backend Python Sênior para o Mercado Internacional

**Perfil:** Transição de carreira | Background em Python backend | 1h/dia de estudo  
**Objetivo:** R$ 13k+ remoto para fora | Foco em system design, arquitetura e cloud  
**Duração:** 24 meses (~670h totais)

---

## Fase 1 — Alicerce Sênior (Meses 1-6)

Elevar o nível do código para o padrão que empresa gringa espera.

| O que estudar | Onde na DIO | Tempo estimado |
|---|---|---|
| FastAPI avançado (async, testes, autenticação) | Bootcamp **Luizalabs Back-end com Python 2ª Ed** — módulo "APIs Modernas com FastAPI do Zero ao Deploy" | 2 meses |
| POO + Design Patterns em Python | Bootcamp **Luizalabs** — módulo "POO na Prática" + Curso **Design Patterns com Java** (conceitos transferíveis) | 1 mês |
| Bancos SQL + NoSQL (modelagem, performance) | Curso **SQL Specialist** + artigos da comunidade DIO | 1 mês |
| Docker + Docker Compose | Curso **Docker Fundamentals** na DIO | 1 mês |
| Testes automatizados com pytest | Conteúdo do Luizalabs + prática nos projetos | 1 mês |

**Marco:** API completa em FastAPI com testes, container Docker e deploy documentado no GitHub.

---

## Fase 2 — Cloud & Infraestrutura (Meses 7-12)

Diferencial que separa um dev que só codar de um profissional completo.

| O que estudar | Onde na DIO | Tempo estimado |
|---|---|---|
| AWS Fundamentals (EC2, S3, VPC, RDS, IAM) | **Bootcamp Cloud AWS** (73h) | 2 meses |
| Linux para servidores | Curso **Linux** na DIO | 1 mês |
| IaC com Terraform | **Aceleração Internacional - IaC with Terraform and Python** (em inglês) | 1 mês |
| CI/CD (GitHub Actions) | Curso **Git CI/CD** na DIO | 1 mês |
| Serverless (Lambda, API Gateway) | Projetos do Bootcamp Cloud AWS + prática | 1 mês |

**Marco:** Aplicação completa rodando na AWS com Terraform, CI/CD e domínio dos serviços principais.

---

## Fase 3 — Arquitetura & System Design (Meses 13-18)

O que separa o nível pleno do sênior: pensar em sistemas, não só em código.

| O que estudar | Onde na DIO | Tempo estimado |
|---|---|---|
| Clean Architecture + Hexagonal Architecture | Bootcamp **Cognizant - Arquitetura com Spring Boot e Cloud** (conceitos transferíveis para Python) | 2 meses |
| Microsserviços, eventos e filas | Conteúdos de microsserviços + artigos da comunidade DIO | 2 meses |
| System Design (escalabilidade, cache, CAP theorem, bancos) | Artigo **"Arquitetura para Sistemas Escaláveis na Nuvem"** na DIO + prática de design | 2 meses |

**Marco:** Conseguir desenhar a arquitetura de um sistema e explicar trade-offs em uma entrevista técnica.

---

## Fase 4 — Preparação pra Gringa (Meses 19-24)

Polish final: certificação, entrevistas em inglês e portfólio de nível internacional.

| O que estudar | Onde na DIO | Tempo estimado |
|---|---|---|
| Certificação AWS Cloud Practitioner | Curso **AWS Cloud Practitioner Certification** na DIO | 1.5 mês |
| System Design interviews (mock em inglês) | Simular com ferramentas de mock interview | 1.5 mês |
| Projeto portfólio de alto nível | Sistema escalável completo em Python + AWS + IaC — README em inglês | 2 meses |
| Inglês técnico (conversação) | **Acelerações Internacionais** da DIO (100% em inglês) + prática semanal | contínuo |

**Marco:** Certificação AWS, portfólio sênior e capacidade de fazer entrevista técnica em inglês.
