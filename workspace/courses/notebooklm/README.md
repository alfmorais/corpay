# Segundo Cérebro de Investimentos com NotebookLM: Metodologia Benjamin Graham

## 📚 Contexto e Objetivos

Este projeto foi desenvolvido como parte do desafio da DIO utilizando o NotebookLM como ferramenta de aprendizagem ativa e organização do conhecimento.

O tema escolhido foi a metodologia de investimentos de Benjamin Graham, considerado o pai do Value Investing e mentor de Warren Buffett.

O objetivo principal deste projeto é construir um "Segundo Cérebro" capaz de consolidar os principais ensinamentos de Graham em uma base de conhecimento estruturada, permitindo consultas rápidas, revisões periódicas e geração de insights para tomada de decisão em investimentos de longo prazo.

### Objetivos de Estudo

* Compreender os princípios fundamentais do Value Investing.
* Entender o conceito de Margem de Segurança.
* Aprender os critérios de seleção de ações propostos por Benjamin Graham.
* Estudar a diferença entre investimento e especulação.
* Criar um repositório de conhecimento reutilizável para futuras análises de empresas.
* Utilizar IA Generativa para acelerar o aprendizado e a organização do conhecimento.

# ⚠️ Cicatrizes e Troubleshooting

Durante o projeto foram encontradas algumas dificuldades:

* Respostas excessivamente genéricas quando os prompts eram muito amplos.
* Necessidade de especificar contexto para evitar resumos superficiais.
* Algumas fontes utilizavam terminologias diferentes para os mesmos conceitos.
* Foi necessário comparar informações entre múltiplas fontes para validar interpretações.

### Estratégias Utilizadas

* Utilização de prompts mais específicos.
* Solicitação de exemplos práticos.
* Comparação entre diferentes fontes.
* Criação de perguntas incrementais em vez de perguntas muito abrangentes.

# 📖 Miniguia de Estudos

## Resumo Estruturado

### 1. Value Investing

Estratégia focada na compra de ativos negociados abaixo do seu valor intrínseco.

### 2. Margem de Segurança

Comprar ativos com desconto suficiente para reduzir riscos e absorver erros de avaliação.

### 3. Sr. Mercado

Metáfora criada por Graham para representar a volatilidade e o comportamento emocional do mercado.

### 4. Investidor Defensivo

Perfil que busca simplicidade, diversificação e baixo risco.

### 5. Investidor Empreendedor

Perfil mais ativo que busca oportunidades através de análises detalhadas.

### 6. Investimento vs Especulação

Investimento envolve análise fundamentada e foco no longo prazo. Especulação busca ganhos rápidos assumindo riscos elevados.

# 📚 Glossário

| Conceito            | Definição                                                         |
| ------------------- | ----------------------------------------------------------------- |
| Value Investing     | Estratégia baseada na compra de ativos abaixo do valor intrínseco |
| Margem de Segurança | Diferença entre preço de mercado e valor estimado                 |
| Valor Intrínseco    | Valor real de um ativo baseado em fundamentos                     |
| Sr. Mercado         | Representação das emoções do mercado                              |
| P/L                 | Relação entre preço da ação e lucro por ação                      |
| P/VPA               | Relação entre preço da ação e valor patrimonial                   |
| Dividend Yield      | Retorno de dividendos pago pela empresa                           |
