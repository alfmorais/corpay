# Study Plan: Python Developer (Mid-level) → Senior Architect & Solution Designer

**Profile:** Mid-level Python developer | ~10h/week (1-2h/day) | Sustainable pace, no rush

---

## Phase 1 — Fundamentals Every Architect Must Master (weeks 1-4)

| Week | DIO Content | Learning Goals |
|------|-------------|----------------|
| 1-2 | **Course:** Python Fundamentals (modules 3-4) | Advanced OOP: encapsulation, inheritance, polymorphism, decorators, iterators |
| 3 | **Course:** Applying Encapsulation in Python | Data protection, properties, OOP best practices |
| 4 | **Article:** Python Best Practices with OOP + **Article:** SOLID in practice | Clean code, single responsibility, composition over inheritance |

**Milestone:** You refactor a legacy project applying SOLID and encapsulation.

---

## Phase 2 — Design Patterns & Engineering Thinking (weeks 5-8)

| Week | DIO Content | Learning Goals |
|------|-------------|----------------|
| 5-6 | **Bootcamp:** Luizalabs Back-end with Python — OOP and FastAPI modules | REST APIs, SQLAlchemy, real-world best practices |
| 7 | **Article:** Architectural Patterns for Beginners + **Article:** Exploring Design Patterns | Factory, Singleton, Observer, Strategy — implemented in Python |
| 8 | **Project Challenge:** Build a banking API with FastAPI applying design patterns | Hands-on project to solidify knowledge |

**Milestone:** You deliver an API with at least 2 design patterns implemented.

---

## Phase 3 — Software Architecture (weeks 9-14)

| Week | DIO Content | Learning Goals |
|------|-------------|----------------|
| 9 | **Course:** Introduction to API Concepts and Clean Architecture | REST architecture, Hexagonal Architecture (Ports & Adapters) |
| 10-11 | Hands-on study: implement Clean Architecture in Python | Domain, application, and infrastructure separation |
| 12 | **Course:** Understanding the MVC Pattern | MVC vs Clean Architecture, when to use each |
| 13 | **Article:** System Design + **Article:** Software Architecture in the AI Era | Design decisions, trade-offs, documentation |
| 14 | **Article:** Software Architecture Fundamentals | Software vs Solutions vs Enterprise Architecture, Conway's Law |

**Milestone:** You model a system from scratch using Clean Architecture in Python.

---

## Phase 4 — Cloud, Microservices & System Design (weeks 15-20)

| Week | DIO Content | Learning Goals |
|------|-------------|----------------|
| 15 | **Course:** Docker Fundamentals | Containers, Dockerfile, docker-compose |
| 16 | **Course:** Kubernetes Fundamentals | Orchestration, pods, services |
| 17-18 | **Career:** Cloud Solution Architect — AWS Cloud Practitioner + Azure AZ-900 courses | Cloud computing, scalability, cost management |
| 19 | **Articles:** Microservices + Event-Driven Architecture | Kafka, messaging, async communication |
| 20 | Hands-on study: design a distributed system architecture | C4 diagrams, ADRs (Architectural Decision Records) |

**Milestone:** You document a system architecture with C4 diagrams and ADRs.

---

## Phase 5 — Final Integration Project (weeks 21-24)

| Week | DIO Content | What to Do |
|------|-------------|------------|
| 21-24 | **Project Challenge + Portfolio** | Build a complete system: Python API with Clean Architecture, Docker containerized, cloud-deployed, documented with C4 |

**Milestone:** Your portfolio showcases an end-to-end solution with architectural vision.

---

## Pro Tips

- Use DIO's **Study Goal** tool (available inside Bootcamps and Formations) to set study days, track progress, and receive email reminders.
- Consistency beats intensity. 1 hour daily is better than 7 hours on a single day.
- Throughout the plan, use the DIO Agent skills whenever you get stuck:
  - `explain-concept` — when a concept isn't clear
  - `unblock-challenge` — when you're stuck on a code or project challenge
- Always build small prototypes to test architectural decisions before committing to them.
