# DIO Agent - Mentor de Estudos com IA

Projeto que configura um **agente de IA mentor** para acompanhar estudantes da [DIO](https://dio.me) em bootcamps, formações e desafios. O agente entende o contexto da plataforma e ajuda a montar planos de estudo, destravar desafios e explicar conceitos — sem entregar respostas prontas.

## Instalação

O script `scripts/install.sh` instala o **OpenCode**, o harness que executa o agente:

```bash
bash scripts/install.sh
```

Isso baixa e configura o OpenCode no sistema. Depois de instalado, abra este diretório no harness e o agente estará pronto para uso.
